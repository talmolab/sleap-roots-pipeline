Nothing blocks the live pipeline today. The red items are risks that grow now that prod users can start runs; the amber ones need a call from Elizabeth.

#106

A pod that never schedules holds its concurrency slot forever.

Both environments share one semaphore, so a stuck staging pod now starves prod users, and vice versa. The fix is a pending-pod timeout on the gated templates.

#63

Both environments' stage folders live under one person's user path, and nothing would recreate them.

A missing folder leaves pods Pending, not Failed. Since 2026-10-04 this covers prod's folder too.

#132
